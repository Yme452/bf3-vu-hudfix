# bf3-vu-hudfix
Based on the open-source project bf3-hudfix (Bartis1313), this project only adds a VU compatibility layer and ini configuration.

Source
Based on the open-source project bf3-hudfix (Bartis1313), this project just adds a VU compatibility layer and an ini config.

Installation
1. Backup the Engine.BuildInfo_Win32_Retail_dll.dll in your game directory
2. Put the patch's Engine.BuildInfo_Win32_Retail_dll.dll and Engine_BuildInfo_orig.dll into the BF3 game folder
3. Copy these two files again to %LocalAppData%VeniceUnleashedclient
4. Put hudfix.ini into DocumentsBattlefield 3
5. Launch VU

Notes & Tweaks
·Since VU uses its own UI, the patch settings page won't show up in the game options menu, so you'll need to tweak it through the config file (hudfix.ini)![Uploading f173dcb04a92a128fb91135fd81c90d8.png…]()
